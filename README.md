# 饥荒存档管理器 (dst-archive-manager)

一款用于管理《饥荒：联机版》(Don't Starve Together) 存档的工具，帮助玩家快速将本地存档转换为专用服务器存档，并提供便捷的服务器管理功能。

## 📋 功能特性

- 🔄 **存档转换** - 一键将本地存档转换为专用服务器存档
- 🗂️ **存档管理** - 查看、选择和管理服务器存档
- 🌍 **世界配置** - 修改世界基础设置（密码、人数、描述等）
- 📦 **模组检测** - 检查服务器模组是否缺失
- 🚀 **服务器控制** - 启动、关闭专用服务器

## 🖥️ 界面预览

![主界面](image.png)

界面分为三个主要区域：
- **左侧**：本地存档列表 (Clusters) - 显示所有本地游戏存档
- **中间**：转换控制与服务器列表 - 执行存档转换操作，管理专用服务器
- **右侧**：详情面板 - 显示选中服务器的详细信息和配置选项

## 🚀 快速开始

### 环境要求

- Windows 操作系统
- 已安装《饥荒：联机版》客户端
- 已安装 **饥荒专用服务器程序** (Don't Starve Together Dedicated Server)

### 首次使用配置

1. **设置路径**
    - **本地存档路径**：通常为 `C:\Users\[用户名]\Documents\Klei\DoNotStarveTogether\[用户ID]\DoNotStarveTogether`
    - **服务器程序路径**：Steam库中专用服务器程序的安装路径，如 `D:\Steam\steamapps\common\Don't Starve Together Dedicated Server`

2. **获取服务器令牌 (Server Token)**

   专用服务器需要令牌才能出现在科雷服务器搜索列表，获取步骤如下：

   **步骤一**：打开游戏客户端，点击左下角 **"账号"** 按钮登录科雷官网

   ![步骤一](获取服务器令牌步骤一.png)

   **步骤二**：进入 [Klei账号页面](https://accounts.klei.com)，点击顶部导航栏的 **"游戏"** → **"《饥荒：联机版》的游戏服务器"**

   ![步骤二](获取服务器令牌步骤二.png)

   **步骤三**：在服务器页面输入服务器名称，点击 **"添加新服务器"**，复制生成的令牌

   ![步骤三](获取服务器令牌步骤三.png)

3. **配置令牌**
    - 将复制的令牌粘贴到管理器顶部的 **"服务器令牌"** 输入框中

## 📖 使用指南

### 转换本地存档为服务器存档

1. 在左侧 **本地存档列表** 中选择要转换的存档
2. 点击中间的 **"→ 转为服务器"** 按钮
3. 转换完成后，存档将出现在 **专用服务器列表** 中

### 启动服务器

1. 在 **专用服务器列表** 中选中要启动的服务器存档
2. 在右侧面板中配置世界选项（可选）
3. 点击启动按钮运行专用服务器

### 模组检测

- 工具会自动获取服务器端所需模组和当前能够加载的模组
- 如有缺失模组，将在模组详情面板中显示出来
- 可以根据缺失的模组信息去Steam库中下载，之后按同步模组按钮进行模组同步

## 📝 注意事项

1. **模组一致性**：确保服务器端安装了客户端存档使用的所有模组，否则可能导致世界生成异常
2. **服务器关闭**：关闭前为了当前进度不丢失，请手动输入c_shutdown()或者点击管理工具的关闭服务器按钮，不要直接用 `"X"` 关闭窗口

## 🔧 常见问题

**Q: 转换后服务器存档在哪里？**  
A: 服务器存档位于 `DoNotStarveTogether` 目录下的 `Server_X` 文件夹中，可以右键点击存档列表选择在文件夹中打开。

**Q: 如何连接专用服务器？**  
A: 首先需要运行服务器存档的电脑能够被好友访问到，这里需要内网穿透，或者使用第三方加速器的虚拟局域网（开房间），
又或者本身与好友就在一个局域网下，非房主用户在页面上按下"~"后出现指令台，输入c_connect("房主ip")。
房主输入c_connect("127.0.0.1")。

**Q: 如何更新服务器模组？**  
A: 本地更新后，请点击同步模组按钮进行模组同步
